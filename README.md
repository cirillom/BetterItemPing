# Better Item Ping

Client-side Risk of Rain 2 item-ping inventory summary.

## Features

- Adds one local chat line when an item or equipment pickup is pinged
- Lists only current party members who own the pickup
- Shows real item stack counts and omits zero-count players
- Leaves ordinary world, object, and enemy pings unchanged
- Uses inventories already replicated by RoR2; no custom networking is added

## Installation

Import the release ZIP as a local mod using r2modman, or install it from Thunderstore.
